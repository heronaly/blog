firefoxの初期設定をココにまとめます。
<!--more-->
設定項目は→

    about:config

    ポップアップウィンドウを無効化

    browser.link.open_newwindow.restriction = 0

    新規タブをアクティブタブのすぐ後ろに表示

    browser.tabs.insertRelatedAfterCurrent = true

    browser.tabs.insertAfterCurrent = true

    ブックマークを新規タブ

    browser.tabs.loadBookmarksInTabs =  true
